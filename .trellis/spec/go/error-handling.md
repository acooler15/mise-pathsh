# 错误处理

> Go 标准惯例 + CLI 语义。greenfield 项目，随首个实现任务固化。

---

- 错误用 `error` 返回，需要补充上下文时用
  `fmt.Errorf("...: %w", err)` 包装，**保留根因链**；不用 panic 表达可预期错误。
- 输入相关的错误（解析失败、非法输入）必须附带定位信息
  （行号 / 变量名），解析库提供的位置信息直接透传，不要吞掉。
- `main` 包集中处理错误：打印到 stderr，以非零码退出；
  库代码只返回错误，不做退出决策。
- **退出码约定**：`0` 成功；`1` 运行时 / 转换失败；`2` 命令行用法错误。
- 不引入第三方错误库，标准库优先。
